# FreeCAD Bridge 0.4.0

Atualização de interface para importar STEP e JSON pelo SketchUp com acesso rápido aos comandos principais.

## Novidades

- Barra FreeCAD Bridge encaixável/flutuante com cinco ícones próprios.
- STEP, JSON, configuração de FreeCADCmd, diagnóstico e sobre/licença.
- Dicas e texto de status, comandos compartilhados com o menu.
- Restauração nativa de posição/visibilidade e opção para mostrar a barra.
- STEP/JSON desabilitados durante conversão externa.
- Documentação revisada, exemplo JSON sintético e empacotamento com ícones.

## Instalar

Baixe FreeCAD_Bridge_0.4.0.rbz, instale no Gerenciador de Extensões e reinicie o SketchUp. Se necessário use Extensões → FreeCAD Bridge → Mostrar barra de ferramentas. Confira Diagnóstico (0.4.0).

Alvo: SketchUp 2026 desktop Windows; FreeCAD instalado para STEP. O importador JSON não inicia FreeCADCmd. A configuração anterior é preservada.

## Escopo e validação

O conversor, cores e reconstrução foram mantidos da 0.3.0. A versão não garante fechamento de qualquer modelo e não corrige falhas conhecidas de criação de faces. Sintaxe, recursos, testes isolados e integridade do RBZ foram conferidos; interface e fluxo completos ainda precisam de validação nos aplicativos.
