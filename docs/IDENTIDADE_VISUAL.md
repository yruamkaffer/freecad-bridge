# Identidade visual

A marca representa uma ponte (transferência entre ambientes CAD) e uma seta (importação). Paleta: fundo #142D3B, verde #42D3BA e laranja #FFB052.

![Marca](assets/freecad_bridge.png)

- [SVG editável](assets/freecad_bridge.svg)
- [PNG transparente de 512 pixels](assets/freecad_bridge.png)
- [ICO com múltiplos tamanhos](assets/freecad_bridge.ico), para atalhos opcionais do Windows.

A barra usa os recursos step e about de 24/32 pixels, com margem externa transparente. Os outros três comandos conservam símbolos próprios. A extensão não modifica associações de arquivo RBZ do Windows.
