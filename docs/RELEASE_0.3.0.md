# FreeCAD Bridge 0.3.0

Importação STEP para SketchUp desktop com FreeCAD em segundo plano, peças separadas, nomes e cores disponíveis no arquivo, reparo limitado e verificação de sólidos.

## Destaques

- Cores uniformes e por face quando associadas com segurança.
- Relatório com índice, nome, estado, Localizar e exportação.
- Fronteiras de materiais coplanares preservadas.
- Estrito com rollback se o componente final não for sólido.
- Autoria de Yruam Kaffer de Faria; PolyForm Noncommercial 1.0.0.

Instale o RBZ pelo Gerenciador de Extensões, reinicie, configure FreeCADCmd e use o menu FreeCAD Bridge. Alvo: Windows / SketchUp 2026 desktop / FreeCAD 1.1 para metadados. Pacote sem assinatura oficial; SHA256 acompanha para integridade.

Sintaxe e testes isolados passaram. Validação completa das novas funções nos aplicativos pendente. Cores precisam estar no STEP; reparos/triangulação podem reduzir cores por face. Não preserva hierarquia original e não garante fechamento universal. Leia README e licença.
