# Exemplo sintético

Abra tetraedro_vermelho.json pelo ícone JSON da barra. O tetraedro tem vértices nos eixos a 10 mm da origem, cor vermelha e volume geométrico de 166,6667 mm³. Não foi extraído de modelo de cliente ou empresa. Usa a mesma licença do projeto.

Este exemplo valida o caminho JSON e não a conversão STEP. `cad_valid` é indicador declarado no exemplo, não resultado de uma execução FreeCAD. A validação final depende do SketchUp. O exemplo está definido no espaço local do contexto de importação.
